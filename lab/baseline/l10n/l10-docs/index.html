Quickstart

Install the Relay CLI, authenticate and deploy your first service in under five minutes.

1. Install

# macOS and Linux
curl -fsSL https://relay.example/install.sh | sh
relay --version
Note: The installer places the relay binary in ~/.relay/bin. Make sure this directory is on your PATH.

2. Log in

Run relay login and follow the prompts. Your token is stored in ~/.relay/credentials.json.

3. Deploy

# deploy the current directory to the "staging" environment
relay deploy --env staging --region eu-west-1 --wait
Warning: Deploying to production replaces the running version. Use --dry-run first to preview the changes.

Options

FlagDescriptionDefault
--envThe target environment.staging
--waitWait until the deployment is healthy before exiting.off

Keyboard shortcuts

Press Ctrl + K to open the command palette, or ? to see all shortcuts.
