Démarrage rapide

Installez la CLI Relay, authentifiez-vous et déployez votre premier service en moins de cinq minutes.

1. Installation

# macOS et Linux
curl -fsSL https://relay.example/install.sh | sh
relay --version
Remarque : l’installateur place le binaire relay dans ~/.relay/bin. Vérifiez que ce répertoire figure dans votre PATH.

2. Connexion

Lancez relay login et suivez les instructions. Votre jeton est enregistré dans ~/.relay/credentials.json.

3. Déploiement

# déployer le répertoire courant dans l'environnement "staging"
relay deploy --env staging --region eu-west-1 --wait
Attention : le déploiement vers production remplace la version en cours d’exécution. Utilisez d’abord --dry-run pour prévisualiser les changements.

Options

OptionDescriptionValeur par défaut
--envL’environnement cible.staging
--waitAttend que le déploiement soit sain avant de quitter.désactivé

Raccourcis clavier

Appuyez sur Ctrl + K pour ouvrir la palette de commandes, ou sur ? pour afficher tous les raccourcis.
